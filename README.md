# Arkanya

Site officiel et infrastructure digitale du projet **Arkanya**.

Arkanya est une plateforme de développement web moderne et un écosystème digital orienté **performance, structuration et
développement sur mesure**.

Le projet inclut :

- un site vitrine professionnel
- un portfolio de réalisations
- une base évolutive pour futurs outils et services digitaux

---

# Aperçu

Arkanya propose des solutions de développement web modernes destinées aux **entreprises souhaitant structurer ou
moderniser leur présence digitale**.

Objectifs du projet :

- créer une présence web professionnelle
- démontrer un savoir-faire technique
- présenter des réalisations
- servir de base pour de futurs outils et services

---

# Technologies utilisées

Ce projet repose sur une stack moderne orientée **performance, SEO et maintenabilité**.

### Frontend

- Next.js 16
- React
- TypeScript
- TailwindCSS

### Performance

- Static Site Generation (SSG)
- Optimisation des images avec Next/Image
- Lazy loading
- Code splitting

### Déploiement

- Vercel

### Outils

- Git
- GitHub
- Node.js
- NPM
