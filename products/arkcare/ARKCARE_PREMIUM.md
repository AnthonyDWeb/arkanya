# ArkCare — périmètre Gratuit et Premium

Décision produit au 2026-07-23. Ce document complète le périmètre V1 local et devient la référence
pour les futurs droits ArkCare.

## Principes

- Les fonctions nécessaires au suivi quotidien ne sont jamais réservées au Premium.
- ArkCare reste utilisable sans compte et hors ligne.
- L’export JSON manuel reste gratuit.
- Premium finance la protection cloud, le multi-appareils, le partage et les analyses avancées.
- Les statistiques restent descriptives et ne donnent aucun conseil médical.
- ArkCare Cloud reste bloqué jusqu’à validation juridique, sécuritaire et d’hébergement.

## Gratuit

- traitements multiples ;
- fréquences supportées et cycles ;
- plusieurs prises quotidiennes ;
- dosage distinct par prise ;
- création, modification et archivage ;
- calendrier et prochaines prises ;
- statuts prise, manquée, reportée et supprimée ;
- report simple ou avec décalage ;
- notifications locales essentielles ;
- historique récent nécessaire au suivi ;
- fonctionnement hors ligne ;
- export et import JSON manuels ;
- suppression complète des données ;
- application Android et mises à jour ;
- avertissement médical et confidentialité.

## ArkCare Premium V1

- sauvegarde cloud sécurisée ;
- restauration après perte ou changement d’appareil ;
- synchronisation multi-appareils ;
- gestion et révocation des appareils ;
- historique étendu ;
- statistiques descriptives détaillées ;
- rapports PDF et CSV ;
- profils familiaux supplémentaires ;
- partage en lecture seule avec un proche ;
- permissions et révocation du partage ;
- journal des accès et modifications sensibles.

## Évolutions Premium prévues

- confirmation autorisée par un proche ;
- rappels secondaires et résumés ;
- suivi du stock et rappels de renouvellement ;
- rapports programmés ;
- filtres avancés ;
- pièces jointes chiffrées ;
- accès professionnel strictement encadré ;
- fonctions intelligentes après consentement et analyse dédiée.

## Conditions préalables au cloud

Avant toute activation, Arkanya doit valider le chiffrement, l’isolation, l’hébergement, les
sauvegardes, la rétention, les consentements, les journaux, la suppression et les obligations
applicables aux données de santé.

Les droits peuvent provenir d’ArkCare Premium, d’Arkanya+, d’un essai, d’un achat, d’un code
universel ou d’un accès manuel.

Avant l’intégration du paiement, toutes les restrictions et fonctions Premium autorisées doivent
être opérationnelles. L’accès est alors accordé par un code configuré ou une attribution
administrative auditée ; aucun contournement local permanent n’est autorisé dans l’application.
